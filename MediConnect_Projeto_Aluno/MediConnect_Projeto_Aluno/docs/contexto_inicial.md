# Contexto inicial — MediConnect
O MediConnect atende pacientes e profissionais em um hospital inteligente. O sistema organiza consultas, internações e exames.

## Stakeholders inicialmente listados
- paciente;
- médico;
- hospital.

> A especificação inicial não detalha laboratório, convênio, recepção, enfermagem, auditoria, responsáveis legais, órgãos reguladores ou outros sistemas externos.
