# Requisitos iniciais

## Requisitos funcionais

* **RF01** — O sistema deve permitir marcar consultas.
* **RF02** — O sistema deve permitir solicitar exames.
* **RF03** — O sistema deve permitir registrar internações.
* **RF04** — O sistema deve avisar o paciente quando necessário.

## Requisitos não funcionais

* **RNF01 — Segurança:** O sistema deve tratar as informações dos pacientes de maneira segura.
* **RNF02 — Desempenho:** O sistema deve responder às operações sem atrasos que prejudiquem sua utilização.
* **RNF03 — Disponibilidade:** O sistema deve possuir disponibilidade adequada para os serviços hospitalares.

## Observações

A priorização inicial desses requisitos, o backlog e o plano de trabalho estão registrados em:

`docs/aula02-processo-design.md`

Os requisitos representam o levantamento inicial do projeto e poderão ser detalhados e evoluídos durante o semestre, incluindo critérios de aceitação, rastreabilidade, privacidade, autorização, indisponibilidade de sistemas parceiros e auditoria.
