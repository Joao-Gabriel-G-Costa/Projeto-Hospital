## Regra para todos os grupos

O NexusLog é exemplo do professor. Em seu projeto, use as classes e o domínio próprios. O que será avaliado é a evidência do conceito da aula e a coerência entre problema, requisito, decisão, modelo e código.

## Fluxo sugerido de entrega no GitHub

1. Criar/usar a Issue da aula.
2. Criar branch da atividade.
3. Implementar/documentar.
4. Executar testes quando houver alteração de comportamento.
5. Fazer commits descritivos.
6. Abrir Pull Request relacionando a Issue.
7. No PR, explicar **o que mudou, por que mudou e como foi verificado**.
