# MediConnect — Aula 14

## Tema
Strategy, Factory Method, Abstract Factory e Observer

## Situação do projeto
O MediConnect contém decisões e artefatos legados que podem estar incompletos, inconsistentes ou inadequados ao conteúdo desta aula. O aluno deve analisar o estado atual antes de modificar.

## O que o aluno deve fazer
1. avaliar as implementações legadas de Strategy, Factory e Observer e decidir o que corrigir, substituir ou remover;
2. aplicar Strategy a uma variação real, como priorização/triagem ou outra política pertinente;
3. avaliar criação de diferentes tipos de consulta/exame para justificar Factory Method;
4. modelar famílias coerentes de serviços/parceiros quando houver justificativa para Abstract Factory;
5. permitir múltiplos interessados em eventos pertinentes usando Observer;
6. revisar conjuntamente os seis padrões e produzir código, UML/Mermaid e ADR para cada padrão mantido.

## Dicas
- Não usar padrão apenas para cumprir lista.
- Aponte explicitamente quando a implementação inicial só imita a aparência de um padrão.

## Evidências mínimas da entrega
- Issue identificada como `Aula 14`.
- Branch sugerida: `aula-14`.
- Commits com mensagens que expliquem mudanças relevantes.
- README/Markdown da entrega contendo **problema observado, alteração realizada e critério de aceitação**.
- PR ou registro equivalente permitindo revisão do grupo.

## Prazo operacional
O trabalho deve começar em sala. O limite de conclusão é o início da aula seguinte, salvo orientação diferente do professor.
