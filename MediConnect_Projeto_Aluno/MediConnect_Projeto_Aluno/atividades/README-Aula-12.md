# Aula 12 — Observer, Adapter e Facade

## Objetivo
Aplicar padrões para notificação/eventos, integração com contrato incompatível e simplificação de subsistemas, sempre orientado ao problema.

## Atividade no projeto do grupo

1. Identifique no projeto uma situação real relacionada ao tema da aula.
2. Registre o problema/necessidade antes de escolher a solução.
3. Produza os artefatos solicitados abaixo com nomes e exemplos do próprio domínio.
4. Quando houver mudança de código, compile e execute os testes antes de concluir.
5. Registre no GitHub a evidência da atividade (Issue/branch/commits/PR).


## Não fazer
- Não copiar nomes de classes do NexusLog apenas para parecer igual ao exemplo.
- Não introduzir tecnologia ou padrão sem justificar o problema que ele resolve.
- Não alterar código sem preservar/verificar o comportamento esperado.

# Entrega — Aula 12
Para cada padrão utilizado:
- problema;
- participantes;
- código e diagrama;
- benefício e trade-off;
- teste demonstrando o comportamento quando aplicável.
