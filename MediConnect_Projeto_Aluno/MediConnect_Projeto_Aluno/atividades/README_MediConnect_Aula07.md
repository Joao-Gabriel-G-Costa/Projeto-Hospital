# MediConnect — Aula 07

## Tema
Estilos arquiteturais e trade-offs

## Situação do projeto
O MediConnect contém decisões e artefatos legados que podem estar incompletos, inconsistentes ou inadequados ao conteúdo desta aula. O aluno deve analisar o estado atual antes de modificar.

## O que o aluno deve fazer
1. comparar monólito, camadas, microsserviços e orientação a eventos para o MediConnect;
2. confrontar `docs/arquitetura_inicial.md` com a implementação real e os requisitos da Aula 06;
3. selecionar e justificar uma arquitetura/estilo ou combinação coerente;
4. substituir ou complementar o ADR-0001 registrando consequências e alternativas.

## Dicas
- Não escolher arquitetura por moda.
- Uma decisão pode manter um monólito se os trade-offs justificarem.

## Evidências mínimas da entrega
- Issue identificada como `Aula 07`.
- Branch sugerida: `aula-07`.
- Commits com mensagens que expliquem mudanças relevantes.
- README/Markdown da entrega contendo **problema observado, alteração realizada e critério de aceitação**.
- PR ou registro equivalente permitindo revisão do grupo.

## Prazo operacional
O trabalho deve começar em sala. O limite de conclusão é o início da aula seguinte, salvo orientação diferente do professor.
