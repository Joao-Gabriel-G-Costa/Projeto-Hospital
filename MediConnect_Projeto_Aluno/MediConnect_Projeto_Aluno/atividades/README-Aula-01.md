# Aula 01 — Fundamentos do Design de Software, contexto e organização da equipe

## Objetivo
Reconhecer conceitos fundamentais de Design de Software, compreender o contexto do projeto e organizar a equipe e o repositório para o desenvolvimento das atividades da Unidade Curricular.

## Atividade no projeto do grupo

1. Identifique e descreva brevemente o contexto do projeto do grupo.
2. Registre o problema ou necessidade que o projeto pretende atender.
3. Identifique os principais usuários, interessados ou stakeholders envolvidos.
4. Organize a equipe, definindo papéis iniciais e responsabilidades de trabalho.
5. Estruture ou revise o repositório GitHub do projeto e registre a evidência da atividade (Issue/branch/commits/PR), quando aplicável.


## Não fazer
- Não copiar o contexto, os nomes ou as regras do NexusLog para o projeto do grupo.
- Não iniciar a atividade propondo tecnologia antes de compreender o problema e o contexto.
- Não atribuir papéis sem registrar minimamente a responsabilidade de cada integrante.

# Entrega — Aula 01
- Registro resumido do contexto do projeto.
- Descrição do problema ou necessidade a ser atendida.
- Identificação inicial de usuários/stakeholders.
- Registro da equipe e divisão inicial de papéis.
- Repositório organizado para acompanhamento das atividades.
- Ficha diagnóstica ou registro inicial do contexto/equipe.
